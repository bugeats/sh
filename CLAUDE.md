# sh

Portable shell environment launched via `nix run github:bugeats/sh --refresh`. Bundles fish, starship, tmux, zellij, git, gitui, and helix with generated config into a single reproducible package.

## Architecture

Each config is an independent flake output package (`packages.*-config`), built to its own nix store path. The `packages.default` wrapper sets env vars pointing to these store paths and bundles all runtime dependencies on PATH. Fish and gitui lack dedicated config env vars, so `bootstrap.sh` symlinks those into `~/.config/` (persisted across sessions; originals backed up with `.bugeats-was-here` suffix on first run).

Config modules come in two shapes: data modules (`starship.nix`, `git.nix`, `gitui.nix`) return pure content from shared inputs (colors); directory modules (`fish/`, `zellij/`) encapsulate config assembly via `default.nix`. The `zellij/` directory concatenates static KDL (`config.kdl`), generated keybinds (loop in `default.nix`), and generated theme (`theme.nix`). `config.kdl` sets `default_layout "disable-status-bar"`, a zellij built-in that keeps the top tab-bar and drops the bottom status bar.

Color values from `github:bugeats/colors` are extracted as both `hexcolors` (for text-format configs) and `rgbcolors` (for zellij's `R G B` theme format).

## Constraints

- **No home-manager.** Config is generated by the flake, delivered via env vars where possible, symlinked by bootstrap.sh otherwise.
- External color values come from `github:bugeats/colors`.
- Zellij built from source via `github:a-kenji/zellij-nix`.

## Build

```
nix build
nix run
```

Files must be git-tracked before `nix build` can read them.

## Current Focus

Zellij is the daily driver via the built-in `disable-status-bar` layout (no custom plugin). `packages.zj` (`flake.nix`) is the launcher (`zellij attach --create <cwd-basename>`), on the bootstrap PATH. Keybind set is settled — see [docs/zellij-keybinds.md](docs/zellij-keybinds.md).

Deferred follow-up: `zellij-nix`'s only rationale was patchable plugins, now gone; only the zellij binary still uses that input, so it could revert to `nixpkgs.zellij`. Held off to avoid version drift.

Long-term goal stands: retire tmux. Still in `flake.nix` `runtimeInputs` and the `tmux-here`/`tmux-hack` fish functions — remove once zellij has settled as the daily driver.
